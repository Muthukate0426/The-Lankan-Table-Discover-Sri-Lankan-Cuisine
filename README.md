# The Lankan Table 🇱🇰🍛

## Overview

**The Lankan Table** is a responsive Sri Lankan cuisine website created to introduce traditional Sri Lankan dishes, authentic flavors, and the rich food culture of Sri Lanka.

This project was developed as a practical frontend project to improve my skills in **HTML, CSS, and JavaScript**.

---

## ✨ Features

* 🏠 Home page with featured Sri Lankan dishes
* 🔎 Food search functionality
* 🍛 Food category navigation
* 📖 Detailed food information
* 📱 Responsive web design
* 🎨 Clean and user-friendly interface
* 📞 Contact page
* ℹ️ About page

### Food Categories

* Rice & Curry
* Street Food
* Breakfast
* Desserts
* Beverages
